# CMA 预警核查与补齐

## 已证实的失败方式

- 五个公报入口不覆盖全国灾害预警入口；大风蓝色预警漏采。
- NMC 页面标题通常只有产品名，发布、颜色与解除动作在正文首段，现有标题规则漏识别。
- 地质灾害、山洪、冰冻、渍涝、森林火险等词汇缺失；联合预警可能在不同地区使用不同颜色。
- 一篇产品可含多个预报时段；按全文省份配统一最高颜色、统一截止时间会误报。
- 官方预警列表有分页，省级滚动栏只是部分条目；市县信号不能表示全省处于同一等级。
- 12379 直连失败，weather.cma.cn 直连返回防火墙页面，不能把 HTTP 200 当作采集成功。

## 实施范围与验收

1. 保留既有公报，增加已在官方导航核实的 12 类全国预警、4 类水文地质风险、强对流与森林火险入口。
2. 仅从标题或正文首段的明确官方发布语句识别颜色与解除；中期展望保持独立。按带颜色的区域段落识别联合风险，不传播标题最高颜色。
3. 读取明确预报时间范围，按区域段落过滤过期时段；未披露截止时间时保留 24 小时展示窗，不能宣称已解除。
4. 接入 NMC 公开查询页面使用的地方预警分页索引，完整遍历、去重、检查数量与截断。地方信号独立展示，不进入省级风险填色；不推断索引未提供的有效/解除状态。
5. 使用保存的官方原始页面和针对性反例验证识别；最终验证 Docker/API、实际看板、省份筛选、分页、来源异常提示，保存报告、页面截图与校验和。

## 边界

公开网页和网页内部查询不是有稳定性承诺的正式业务接口。源站更新期间分页不是原子快照；完整性检查失败保留旧快照并显示异常。更严格的市县预警生命周期、地理多边形与长期历史，需要获得正式数据服务支持，不能用模型臆测。
